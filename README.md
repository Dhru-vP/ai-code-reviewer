# 🚀 AI Code Reviewer

An AI-powered web app that analyzes code and provides feedback on bugs, improvements, and optimized versions.

## 🌐 Live Demo
Frontend: https://your-app.vercel.app  
Backend: https://your-backend.onrender.com

## ⚙️ Tech Stack
- Frontend: React
- Backend: Node.js, Express
- AI: Groq API (LLM)
- Deployment: Vercel + Render

## ✨ Features
- Paste code and get instant AI review
- Bug detection & improvement suggestions
- Optimized code output
- Clean developer-style UI

## 🧪 How it works
1. User inputs code in frontend
2. Request sent to backend API
3. Backend calls LLM (Groq)
4. Response returned and displayed
